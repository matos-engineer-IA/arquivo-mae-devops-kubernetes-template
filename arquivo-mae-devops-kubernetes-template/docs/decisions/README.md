# Registros de decisão arquitetural

Use um ADR quando uma decisão:

- alterar arquitetura;
- escolher tecnologia;
- definir contrato importante;
- afetar segurança;
- criar restrição de longo prazo;
- substituir uma decisão anterior.

Copie `ADR-000-TEMPLATE.md`, incremente o número e use um título objetivo.

Estados sugeridos:

- PROPOSTO
- ACEITO
- REJEITADO
- SUBSTITUÍDO
- OBSOLETO
