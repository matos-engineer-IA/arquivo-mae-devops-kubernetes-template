# Scripts do projeto

Use esta pasta para comandos repetíveis de desenvolvimento, validação, migração e operação.

Cada script deve informar:

- finalidade;
- parâmetros;
- ambientes permitidos;
- efeitos colaterais;
- pré-requisitos;
- exemplo seguro;
- como reverter;
- responsável.

Scripts destrutivos devem exigir confirmação explícita, oferecer `dry-run` quando possível e nunca conter credenciais.
