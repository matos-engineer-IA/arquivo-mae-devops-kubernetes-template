# Protótipos

Use esta pasta para materiais ainda não considerados implementação oficial:

- wireframes;
- fluxos de tela;
- exemplos de payload;
- provas de conceito;
- respostas simuladas.

Todo protótipo deve informar:

- objetivo;
- responsável;
- data;
- limitações;
- o que é fictício;
- condição para se tornar oficial.
