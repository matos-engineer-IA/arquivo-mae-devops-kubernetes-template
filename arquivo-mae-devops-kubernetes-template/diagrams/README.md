# Diagramas

Os arquivos `.mmd` usam sintaxe Mermaid.

Regras:

- mantenha cada diagrama pequeno;
- use nomes iguais aos componentes documentados;
- não inclua credenciais, dados pessoais ou URLs privadas desnecessárias;
- atualize o diagrama quando o fluxo ou a arquitetura mudar;
- referencie o ADR relacionado quando houver mudança estrutural.

- `pipeline-devops.mmd`: fluxo Git -> Drone -> Kubernetes/Rancher.
