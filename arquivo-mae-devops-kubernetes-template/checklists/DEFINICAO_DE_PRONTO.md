# Definição de pronto

- [ ] Critérios de aceitação atendidos.
- [ ] Mudança restrita ao escopo.
- [ ] Diff revisado e sem segredo.
- [ ] Testes, lint, tipos e build executados.
- [ ] Documentação atualizada.
- [ ] Compatibilidade e casos de erro avaliados.
- [ ] Reversão conhecida.
- [ ] Commit/build/imagem rastreáveis.
- [ ] Pipeline e gates concluídos.
- [ ] Deploy, quando aplicável, teve dry-run, diff, rollout e smoke test.
- [ ] Contexto/namespace e aprovações registrados.
- [ ] Limitações e pendências registradas.
- [ ] `docs/CHANGELOG_IA.md` atualizado quando houve IA.
