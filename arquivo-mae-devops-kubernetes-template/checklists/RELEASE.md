# Checklist de release

- [ ] Commit e build Drone identificados.
- [ ] CI, testes e segurança aprovados.
- [ ] Imagem imutável e digest registrados.
- [ ] Mesma imagem será promovida entre ambientes.
- [ ] Manifest renderizado sem placeholders.
- [ ] Contexto e namespace confirmados.
- [ ] RBAC mínimo verificado.
- [ ] Dry-run local e server-side executados.
- [ ] `kubectl diff` revisado.
- [ ] Migrações têm backup, compatibilidade e rollback.
- [ ] Aprovação e ticket de mudança presentes.
- [ ] Rollout e smoke tests definidos.
- [ ] Dashboards, logs e alertas disponíveis.
- [ ] Procedimento de rollback conhecido.
- [ ] Changelog e evidências preparados.
